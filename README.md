# 🎨 Color Picker App

A simple and interactive **Color Picker Web Application** built using **HTML, CSS, and JavaScript**.  
It allows users to pick colors, generate random colors, and save selected colors in a palette.

---

## 🚀 Features

- 🎯 Pick colors using a color input tool  
- 🔀 Generate random hex colors  
- 🎨 Display selected color with hex code  
- 🧩 Save selected colors in a palette  
- 🖱️ Click palette colors to reuse them  
- 📱 Responsive and clean UI  

---

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (Vanilla JS)** – Functionality
